# Birthday Website 💗

Website ulang tahun interaktif dengan tema cute & playful.

## Struktur
- index.html
- style.css
- script.js
- images/foto1.jpg
- images/foto2.jpg
- images/foto3.jpg
- images/foto4.jpg
- images/couple.jpg
- music/romantic-song.mp3

## Cara menggunakan

1. Buka folder website.
2. Masukkan foto kalian ke folder `images`.
3. Nama file foto:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - couple.jpg
4. Masukkan musik MP3 ke:
   `music/romantic-song.mp3`
5. Buka `index.html` di Chrome/Edge.
6. Cari teks `[NAMA]` dan `[NAMA KAMU]` di `index.html`, lalu ganti dengan nama yang sesuai.
7. Edit isi surat jika ingin dibuat lebih personal.

## Catatan
Website tetap berjalan walaupun foto/musik belum dimasukkan karena terdapat placeholder gambar.
Untuk pengalaman terbaik di HP, buka dengan browser modern.
